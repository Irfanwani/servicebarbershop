# Archived

This repository is **archived and no longer maintained.** Nothing here has
changed since February 2024.

## Where it went

The app was rebuilt on Expo SDK 54 and now lives alongside the backend in one
repository:

**https://github.com/Irfanwani/barbershop**

| This repository | Now |
| --- | --- |
| this app | `apps/mobile/` |
| the provider app (`barbershopui`) | `apps/mobile/` — same app, provider mode |
| the backend | `services/api/` |

## Why it was replaced

This app and `barbershopui` were two React Native apps that shared a backend by
accident rather than by contract. One held auth, the other held shops, and a
user existed in both. Every fix had to be made twice, in two codebases that had
drifted apart, and the two apps had separate notification preferences stored in
separate places — so there was no way to stop a push you did not want.

The replacement is one app where a role is a field on one account.

## What changed

- **Roles, not apps.** A customer and a provider are the same account with
  different capabilities. Switching does not sign you out.
- **One set of notification preferences**, with marketing opt-in rather than
  opt-out.
- **Reminders that actually arrive**, scheduled on the server rather than
  depending on the app being open.
- **Per-day opening hours.** One opening time and one closing time cannot
  express "closed on Sunday, and only until six on Saturday".
- **Expo SDK 54**, so the native folders here are generated by `expo prebuild`
  rather than committed.

## Your assets

The launcher icon and splash screen in this repository were the source for the
